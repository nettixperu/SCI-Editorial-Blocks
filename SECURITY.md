# Security Policy

## Supported versions

The current development branch and current 0.4.x release line are supported.

| Version | Supported |
|---|---|
| `main` | Yes |
| `0.4.x` | Yes |
| `< 0.4` | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's security reporting features when available. Do not disclose sensitive vulnerability details in public issues or discussions. No private reporting URL, email address, or response-time commitment is currently specified.

## Scope

The plugin does not add external API integrations, telemetry, custom database tables, or frontend JavaScript. Security reports involving the PHP code, Gutenberg integration, block rendering, input handling, or output escaping are still in scope. These design choices are not a guarantee that the plugin is free of security issues.
